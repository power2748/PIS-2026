## Ход выполнения работы
 
### 1. Repository (PostgreSQL)
 
**Реализованные методы:**
 
- `save(order, idempotency_key)` — вставка или обновление агрегата (upsert)
- `find_by_id(order_id)` — поиск заказа по ID
- `find_by_table_id(table_id)` — поиск активного заказа на столике
- `find_by_statuses(statuses, offset, limit)` — список заказов с фильтром и пагинацией
- `find_by_idempotency_key(key)` — проверка дубликата команды
**Технологии:** SQLAlchemy 2.0 (Core + ORM), Alembic, PostgreSQL 15

```python
# infrastructure/db/models.py
from sqlalchemy import (

from sqlalchemy.orm import DeclarativeBase, relationship

class Base(DeclarativeBase):

    __tablename__ = "order_items"
 
    item_id   = Column(String(36), primary_key=True)
```

```python
# infrastructure/adapter/out/postgres_order_repository.py
from typing import Optional, List, Set
from sqlalchemy.orm import Session
from sqlalchemy.dialects.postgresql import insert as pg_insert
 
from application.port.out.order_repository import IOrderRepository
from infrastructure.db.models import (
    OrderModel, OrderItemModel, KitchenTicketModel,
    TicketItemModel, PaymentModel, IdempotentRequestModel,
)
from infrastructure.db.mapper import OrderMapper
from domain.aggregates.order import Order
 
 
class PostgresOrderRepository(IOrderRepository):
    """
    Исходящий адаптер: хранение заказов в PostgreSQL.
    Реализует IOrderRepository из application/port/out/.
    Использует SQLAlchemy ORM для маппинга агрегатов.
    Domain-модели не знают о SQLAlchemy — маппинг в отдельном классе.
    """
 
    def __init__(self, session: Session):
        self._session = session
 
    # ── Запись ────────────────────────────────────────────────────
 
    def save(self, order: Order, idempotency_key: Optional[str] = None) -> None:
        """
        Upsert агрегата Order и всех его дочерних сущностей.
        Использует PostgreSQL INSERT ... ON CONFLICT DO UPDATE.
        """
        existing = self._session.get(OrderModel, order.order_id)
 
        if existing is None:
            # INSERT
            orm_order = OrderMapper.to_orm(order)
            self._session.add(orm_order)
        else:
            # UPDATE — обновляем поля корня агрегата
            existing.status    = order.status.value
            existing.version   = order.version
            existing.comment   = order._comment
            existing.updated_at = order._updated_at
 
            # Синхронизируем позиции (пересоздаём для простоты)
            for item_orm in existing.items:
                self._session.delete(item_orm)
            self._session.flush()
            for item in order.items:
                self._session.add(OrderMapper.item_to_orm(item, order.order_id))
 
            # Синхронизируем тикет
            if order.kitchen_ticket and not existing.kitchen_ticket:
                self._session.add(
                    OrderMapper.ticket_to_orm(order.kitchen_ticket)
                )
            elif order.kitchen_ticket and existing.kitchen_ticket:
                existing.kitchen_ticket.status = order.kitchen_ticket.status
 
            # Синхронизируем платёж
            if order.payment and not existing.payment:
                self._session.add(
                    OrderMapper.payment_to_orm(order.payment)
                )
            elif order.payment and existing.payment:
                existing.payment.status         = order.payment.status
                existing.payment.retry_count    = order.payment.retry_count
                existing.payment.transaction_id = order.payment._transaction_id
 
        # Сохраняем idempotency_key если передан
        if idempotency_key:
            idem = IdempotentRequestModel(
                idempotency_key=idempotency_key,
                order_id=order.order_id,
            )
            self._session.merge(idem)
 
        self._session.flush()
 
    # ── Чтение ────────────────────────────────────────────────────
 
    def find_by_id(self, order_id: str) -> Optional[Order]:
        orm = (
            self._session.query(OrderModel)
            .filter(OrderModel.order_id == order_id)
            .first()
        )
        return OrderMapper.to_domain(orm) if orm else None
 
    def find_by_table_id(self, table_id: int) -> Optional[Order]:
        active_statuses = ["NEW", "IN_PROGRESS", "READY", "AWAITING_PAYMENT"]
        orm = (
            self._session.query(OrderModel)
            .filter(
                OrderModel.table_id == table_id,
                OrderModel.status.in_(active_statuses),
            )
            .first()
        )
        return OrderMapper.to_domain(orm) if orm else None
 
    def find_by_statuses(
        self, statuses: Set[str], offset: int = 0, limit: int = 20
    ) -> List[Order]:
        orms = (
            self._session.query(OrderModel)
            .filter(OrderModel.status.in_(statuses))
            .order_by(OrderModel.created_at.desc())
            .offset(offset)
            .limit(limit)
            .all()
        )
        return [OrderMapper.to_domain(o) for o in orms]
 
    def find_by_idempotency_key(self, key: str) -> Optional[Order]:
        idem = self._session.get(IdempotentRequestModel, key)
        if idem is None:
            return None
        return self.find_by_id(idem.order_id)
```
 
**Маппер (domain ↔ ORM):**
 
```python
# infrastructure/db/mapper.py
from infrastructure.db.models import (
    OrderModel, OrderItemModel, KitchenTicketModel,
    TicketItemModel, PaymentModel,
)
from domain.aggregates.order import Order
from domain.entities.order_item import OrderItem
from domain.entities.kitchen_ticket import KitchenTicket, TicketItem
from domain.entities.payment import Payment
from domain.value_objects.money import Money
from domain.value_objects.order_status import OrderStatus
from domain.value_objects.dish_station import DishStation
from domain.value_objects.table_number import TableNumber
 
 
class OrderMapper:
    """Двунаправленный маппинг: Domain Aggregate ↔ SQLAlchemy ORM Model"""
 
    @staticmethod
    def to_orm(order: Order) -> OrderModel:
        orm = OrderModel(
            order_id=order.order_id,
            table_id=order.table_number.value,
            guests=order._guests,
            status=order.status.value,
            comment=order._comment,
            version=order.version,
            created_at=order._created_at,
            updated_at=order._updated_at,
        )
        orm.items = [
            OrderMapper.item_to_orm(item, order.order_id)
            for item in order.items
        ]
        if order.kitchen_ticket:
            orm.kitchen_ticket = OrderMapper.ticket_to_orm(order.kitchen_ticket)
        if order.payment:
            orm.payment = OrderMapper.payment_to_orm(order.payment)
        return orm
 
    @staticmethod
    def item_to_orm(item: OrderItem, order_id: str) -> OrderItemModel:
        return OrderItemModel(
            item_id=item.item_id,
            order_id=order_id,
            dish_id=item.dish_id,
            dish_name=item.dish_name,
            quantity=item.quantity,
            price=item.price.amount,
            station=item.station.value,
            comment=item.comment,
        )
 
    @staticmethod
    def ticket_to_orm(ticket: KitchenTicket) -> KitchenTicketModel:
        orm = KitchenTicketModel(
            ticket_id=ticket.ticket_id,
            order_id=ticket.order_id,
            status=ticket.status,
        )
        orm.items = [
            TicketItemModel(
                ticket_id=ticket.ticket_id,
                dish_id=i.dish_id,
                dish_name=i.dish_name,
                quantity=i.quantity,
                station=i.station,
                is_done=int(i.is_done),
            )
            for i in ticket.items
        ]
        return orm
 
    @staticmethod
    def payment_to_orm(payment: Payment) -> PaymentModel:
        return PaymentModel(
            payment_id=payment.payment_id,
            order_id=payment.order_id,
            amount=payment.amount.amount,
            currency=payment.amount.currency,
            method=payment._method,
            status=payment.status,
            retry_count=payment.retry_count,
            transaction_id=payment._transaction_id,
        )
 
    @staticmethod
    def to_domain(orm: OrderModel) -> Order:
        """ORM → Domain Aggregate (восстановление агрегата из БД)"""
        order = object.__new__(Order)
        order._order_id    = orm.order_id
        order._table_number = TableNumber(orm.table_id)
        order._guests      = orm.guests
        order._status      = OrderStatus(orm.status)
        order._comment     = orm.comment
        order._version     = orm.version
        order._created_at  = orm.created_at
        order._updated_at  = orm.updated_at
        order._events      = []
 
        order._items = [
            OrderItem(
                item_id=i.item_id,
                dish_id=i.dish_id,
                dish_name=i.dish_name,
                quantity=i.quantity,
                price=Money(i.price, "RUB"),
                station=DishStation(i.station),
                comment=i.comment,
            )
            for i in orm.items
        ]
 
        order._kitchen_ticket = None
        if orm.kitchen_ticket:
            t = orm.kitchen_ticket
            ticket_items = [
                TicketItem(
                    dish_id=ti.dish_id,
                    dish_name=ti.dish_name,
                    quantity=ti.quantity,
                    station=ti.station,
                )
                for ti in t.items
            ]
            kt = object.__new__(KitchenTicket)
            kt._ticket_id = t.ticket_id
            kt._order_id  = t.order_id
            kt._status    = t.status
            kt._items     = ticket_items
            order._kitchen_ticket = kt
 
        order._payment = None
        if orm.payment:
            p = orm.payment
            payment = object.__new__(Payment)
            payment._payment_id    = p.payment_id
            payment._order_id      = p.order_id
            payment._amount        = Money(p.amount, p.currency)
            payment._method        = p.method
            payment._status        = p.status
            payment._retry_count   = p.retry_count
            payment._transaction_id = p.transaction_id
            order._payment = payment
 
        return order
```

**Реализация контроллера (FastAPI):**
 
```python
# infrastructure/adapter/in/order_controller.py
from fastapi import APIRouter, Depends, HTTPException, Header, status
from pydantic import BaseModel, Field
from typing import List, Optional
 
from application.command.create_order_command import CreateOrderCommand, OrderItemData
from application.command.send_to_kitchen_command import SendToKitchenCommand
from application.command.initiate_payment_command import InitiatePaymentCommand
from application.command.complete_payment_command import CompletePaymentCommand
from application.command.cancel_order_command import CancelOrderCommand
from application.query.get_order_by_id_query import GetOrderByIdQuery
from application.query.list_active_orders_query import ListActiveOrdersQuery
from application.service.order_service import OrderService
from domain.exceptions.domain_exception import (
    OrderNotFoundException, TableOccupiedException,
    DishUnavailableException, InvalidOrderStateException,
)
from infrastructure.config.dependency_injection import get_order_service
 
router = APIRouter(prefix="/api/orders", tags=["Orders"])
 
 
# ── Request/Response Pydantic-схемы ───────────────────────────────
 
class OrderItemRequest(BaseModel):
    dish_id: str   = Field(..., min_length=1)
    dish_name: str = Field(..., min_length=1)
    quantity: int  = Field(..., gt=0)
    price: float   = Field(..., ge=0)
    station: str   = Field(..., pattern="^(GRILL|PASTA|DESSERT|BAR|COLD)$")
    comment: Optional[str] = None
 
class CreateOrderRequest(BaseModel):
    table_id: int          = Field(..., gt=0, le=999)
    guests: int            = Field(..., gt=0)
    items: List[OrderItemRequest] = Field(..., min_length=1)
    comment: Optional[str] = None
 
class SendToKitchenRequest(BaseModel):
    waiter_id: str = Field(..., min_length=1)
 
class InitiatePaymentRequest(BaseModel):
    payment_method: str = Field(..., pattern="^(CARD|CASH|QR)$")
    tip: float          = Field(default=0.0, ge=0)
 
class ConfirmPaymentRequest(BaseModel):
    payment_id: str    = Field(..., min_length=1)
    transaction_id: str = Field(..., min_length=1)
 
class CancelOrderRequest(BaseModel):
    reason: Optional[str] = ""
 
class OrderIdResponse(BaseModel):
    order_id: str
 
class TicketIdResponse(BaseModel):
    ticket_id: str
 
class PaymentIdResponse(BaseModel):
    payment_id: str
 
 
# ── Endpoints ─────────────────────────────────────────────────────
 
@router.post("", status_code=status.HTTP_201_CREATED, response_model=OrderIdResponse)
def create_order(
    body: CreateOrderRequest,
    idempotency_key: Optional[str] = Header(None, alias="Idempotency-Key"),
    service: OrderService = Depends(get_order_service),
):
    """Создать новый заказ для столика"""
    try:
        command = CreateOrderCommand(
            table_id=body.table_id,
            guests=body.guests,
            items=[
                OrderItemData(
                    dish_id=i.dish_id, dish_name=i.dish_name,
                    quantity=i.quantity, price=i.price,
                    station=i.station, comment=i.comment,
                )
                for i in body.items
            ],
            comment=body.comment,
            idempotency_key=idempotency_key,
        )
        order_id = service.create_order(command)
        return OrderIdResponse(order_id=order_id)
 
    except TableOccupiedException as e:
        raise HTTPException(status_code=409, detail=str(e))
    except DishUnavailableException as e:
        raise HTTPException(status_code=422, detail=str(e))
    except ValueError as e:
        raise HTTPException(status_code=400, detail=str(e))
 
 
@router.post("/{order_id}/send", response_model=TicketIdResponse)
def send_to_kitchen(
    order_id: str,
    body: SendToKitchenRequest,
    service: OrderService = Depends(get_order_service),
):
    """Отправить заказ на кухню"""
    try:
        command = SendToKitchenCommand(order_id=order_id, waiter_id=body.waiter_id)
        ticket_id = service.send_to_kitchen(command)
        return TicketIdResponse(ticket_id=ticket_id)
    except OrderNotFoundException as e:
        raise HTTPException(status_code=404, detail=str(e))
    except InvalidOrderStateException as e:
        raise HTTPException(status_code=409, detail=str(e))
 
 
@router.post("/{order_id}/pay", response_model=PaymentIdResponse)
def initiate_payment(
    order_id: str,
    body: InitiatePaymentRequest,
    service: OrderService = Depends(get_order_service),
):
    """Инициировать оплату заказа"""
    try:
        command = InitiatePaymentCommand(
            order_id=order_id,
            payment_method=body.payment_method,
            tip=body.tip,
        )
        payment_id = service.initiate_payment(command)
        return PaymentIdResponse(payment_id=payment_id)
    except OrderNotFoundException as e:
        raise HTTPException(status_code=404, detail=str(e))
    except InvalidOrderStateException as e:
        raise HTTPException(status_code=409, detail=str(e))
 
 
@router.post("/payments/{payment_id}/confirm", status_code=status.HTTP_204_NO_CONTENT)
def confirm_payment(
    payment_id: str,
    body: ConfirmPaymentRequest,
    service: OrderService = Depends(get_order_service),
):
    """Подтвердить успешное списание от эквайринга (вызывает PaymentWorker)"""
    try:
        command = CompletePaymentCommand(
            payment_id=payment_id,
            transaction_id=body.transaction_id,
        )
        service.complete_payment(command)
    except OrderNotFoundException as e:
        raise HTTPException(status_code=404, detail=str(e))
 
 
@router.delete("/{order_id}", status_code=status.HTTP_204_NO_CONTENT)
def cancel_order(
    order_id: str,
    body: CancelOrderRequest,
    service: OrderService = Depends(get_order_service),
):
    """Отменить заказ"""
    try:
        service.cancel_order(CancelOrderCommand(order_id=order_id, reason=body.reason))
    except OrderNotFoundException as e:
        raise HTTPException(status_code=404, detail=str(e))
    except InvalidOrderStateException as e:
        raise HTTPException(status_code=409, detail=str(e))
 
 
@router.get("/{order_id}")
def get_order(
    order_id: str,
    service: OrderService = Depends(get_order_service),
):
    """Получить заказ по ID"""
    try:
        return service.get_order_by_id(GetOrderByIdQuery(order_id=order_id))
    except OrderNotFoundException as e:
        raise HTTPException(status_code=404, detail=str(e))
 
 
@router.get("")
def list_active_orders(
    page: int = 1,
    page_size: int = 20,
    status_filter: Optional[str] = None,
    service: OrderService = Depends(get_order_service),
):
    """Список активных заказов в зале с пагинацией"""
    query = ListActiveOrdersQuery(
        page=page,
        page_size=page_size,
        status_filter=status_filter,
    )
    return service.list_active_orders(query)
```

```python
# infrastructure/config/dependency_injection.py
from fastapi import Depends
```

```python
# infrastructure/adapter/out/rabbitmq_event_publisher.py
import json
import pika
import os
from application.port.out.event_publisher import IEventPublisher
from domain.events.order_events import (
    OrderCreatedEvent, OrderSentToKitchenEvent,
    PaymentInitiatedEvent, PaymentCompletedEvent, OrderCancelledEvent,
)
 
ROUTING_KEYS = {
    OrderCreatedEvent:      "order.created",
    OrderSentToKitchenEvent:"order.sent_to_kitchen",
    PaymentInitiatedEvent:  "payment.initiated",
    PaymentCompletedEvent:  "payment.completed",
    OrderCancelledEvent:    "order.cancelled",
}
 
 
class RabbitMQEventPublisher(IEventPublisher):
    """
    Исходящий адаптер: публикация доменных событий в RabbitMQ.
    Использует topic exchange 'restaurant.events'.
    При недоступности RabbitMQ логирует ошибку и не падает (best-effort).
    """
 
    EXCHANGE = "restaurant.events"
 
    def __init__(self):
        self._url = os.getenv("RABBITMQ_URL", "amqp://guest:guest@localhost:5672/")
 
    def publish(self, event) -> None:
        routing_key = ROUTING_KEYS.get(type(event))
        if routing_key is None:
            return  # неизвестное событие — пропускаем
 
        payload = json.dumps(self._serialize(event))
        try:
            connection = pika.BlockingConnection(pika.URLParameters(self._url))
            channel = connection.channel()
            channel.exchange_declare(
                exchange=self.EXCHANGE,
                exchange_type="topic",
                durable=True,
            )
            channel.basic_publish(
                exchange=self.EXCHANGE,
                routing_key=routing_key,
                body=payload.encode(),
                properties=pika.BasicProperties(
                    delivery_mode=2,    # persistent message
                    content_type="application/json",
                ),
            )
            connection.close()
        except Exception as exc:
            # best-effort: не откатываем транзакцию из-за сбоя шины
            print(f"[EventPublisher] WARNING: не удалось опубликовать {routing_key}: {exc}")
 
    @staticmethod
    def _serialize(event) -> dict:
        return {
            k: str(v) for k, v in vars(event).items()
        }
```

## Контрольные вопросы
 
1. **Почему Repository находится в Infrastructure, а не в Domain?**
   - Domain описывает бизнес-правила и не должен знать о способе хранения данных. Репозиторий — это деталь реализации: сегодня PostgreSQL, завтра MongoDB или in-memory для тестов. Если репозиторий в Domain, то Domain начинает зависеть от конкретной СУБД, фреймворка и SQL — это нарушает Dependency Rule гексагональной архитектуры. В Infrastructure репозиторий реализует интерфейс `IOrderRepository` из Application, и Domain не знает о его существовании.
2. **В чём преимущество ORM над обычным SQL?**
   - ORM (SQLAlchemy) позволяет работать с объектами Python, а не строками SQL: маппер преобразует `Order` → `OrderModel` и обратно, не засоряя доменный код SQL-запросами. Миграции Alembic автоматически генерируются из изменений ORM-моделей — не нужно писать `ALTER TABLE` вручную. Unit of Work (сессия) отслеживает изменения объектов и сам строит нужные INSERT/UPDATE. Минус ORM — скрытые N+1 запросы, которые решаются через `joinedload` / `selectinload`.
3. **Зачем использовать миграции вместо ручного CREATE TABLE?**
   - Миграции (Alembic) версионируют схему БД так же, как Git версионирует код: каждое изменение — отдельный файл с `upgrade()` и `downgrade()`. Это позволяет воспроизвести точное состояние БД на любом окружении (dev, staging, prod), откатить схему при ошибке и отследить, кто и когда добавил колонку. Ручной `CREATE TABLE` не масштабируется: при командной разработке неизбежны конфликты и расхождения схем между разработчиками.
4. **Как testcontainers упрощает интеграционное тестирование?**
   - testcontainers запускает реальный Docker-контейнер с PostgreSQL прямо в тесте, не требуя отдельно поднятой БД. Тест получает настоящую СУБД с реальными транзакциями и индексами — это выявляет ошибки, которые невидимы с in-memory заглушками (например, нарушение уникального ограничения или неправильный тип колонки). После теста контейнер уничтожается — полная изоляция без ручной очистки.
5. **Почему REST Controller не вызывает напрямую доменные модели?**
   - Контроллер — входящий адаптер: он отвечает только за перевод HTTP-запроса во внутреннюю команду и обратно. Если контроллер вызывает `Order.send_to_kitchen()` напрямую, он берёт на себя ответственность за транзакции, события и репозиторий — это нарушает SRP. При смене транспорта (например, замена REST на gRPC) придётся переписывать бизнес-логику. Через `OrderService` контроллер остаётся тонким слоем: принял запрос → построил команду → вернул ответ.

Реализован полноценный инфраструктурный слой ресторанной системы. `PostgresOrderRepository` реализует `IOrderRepository` через SQLAlchemy ORM с двунаправленным маппером `OrderMapper`, который изолирует доменные агрегаты от деталей СУБД — ни один доменный класс не содержит импортов SQLAlchemy. Интеграционные тесты на testcontainers проверяют полный цикл: save → commit → find, включая idempotency_key, пагинацию и корректность восстановления агрегата из БД.
